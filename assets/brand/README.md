# Lumo brand

The mark is a lit board: five tickets in columns, with one in the Done column lit amber.

| File | Use |
|---|---|
| `lumo-logo.svg` / `lumo-logo-dark.svg` | Mark and wordmark, for light and dark backgrounds |
| `lumo-mark.svg` / `lumo-mark-dark.svg` | Mark alone |
| `lumo-icon.svg` | App icon, avatars, social previews |
| `favicon.svg` | Browser tab icon (larger mark, tuned for 16–32 px) |

## Colours

| Name | Hex |
|---|---|
| Ink | `#14161F` |
| Amber | `#F5B83D` |
| Paper | `#F4F3EE` (on dark), `#FAFAF7` (page background) |

## Type

The wordmark is [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque) Bold
(SIL Open Font License), lowercase, tracking −2.5 px at 64 px. In the SVGs it is converted to
outlines, so the files render without the font installed.
